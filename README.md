# أين يوجد ماء الأرض؟ وكيف نخزّنه؟

صفحة تعليمية تفاعلية (علوم – الصف السادس الابتدائي): توزيع المياه على الأرض، أنواع الماء العذب، والخزانات الطبيعية والاصطناعية.

- ملف واحد `index.html` بدون أي مكتبات، ويعمل على الهاتف والحاسوب.
- الصور تُحمَّل من ويكيميديا كومنز (تحتاج اتصالاً بالإنترنت).

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع الملفات إليه (فرع `main`).
2. من **Settings → Pages** اختر **Source: GitHub Actions**.
3. بعد اكتمال النشر يظهر الرابط: `https://USERNAME.github.io/REPO/`
